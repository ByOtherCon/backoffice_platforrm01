# How byOther proposals are written (from real proposals sent to GCs)

These rules come from proposals byOther has sent (TJX HomeGoods – Orlando for Quantum Installation Group, Burlington – Ocala for Diamond
Contractors). Every proposal must read like these: short task lines a person would write, not a copy of the plans.

## Rules

1. One section per trade. The section starts with the trade name in capitals (DEMOLITION, FRAMING, CARPENTRY, PAINT, CONCRETE CUTTING AND
   POURBACK). The price is a single lump sum for the trade, whole dollars.
2. Each line names the task: "Remove and dispose of:", "Furnish and install interior partition type B", "Install wall bumpers",
   "Prime and paint interior surfaces per finish plan, floor plan and elevations".
3. Use bullet levels the way the samples do:
   - Level 1: the task.
   - Level 2: what the task is made of (height, stud size and gauge, board, insulation, finish, color, product).
   - Level 3: only a short qualifier of a level-2 line ("Prep for new", "Cut and cap lines as required", "Sales floor: Eggshell finish").
4. Specs, keynote numbers and sheet or detail call-outs are the exception, not the rule. Use one only when the item is on a detail or a
   schedule and the GC needs it to know what is priced ("as required per detail B/C3", "286- Install 1/2" x 7.9" x 48" white oak wall
   panels", "Toilet partition / Color: sandy beach #21-50"). Never put a keynote code in front of every line.
5. Do not repeat the plans' wording or list every note. Group like items: "Remove and dispose of:" followed by the items as level-2 lines.
6. A sub-heading inside a trade is allowed when a trade has distinct parts (STRUCTURAL FRAMING AND BLOCKING under FRAMING; CEILING;
   PHASED BOH AND SALES AREA).
7. Close each trade with the lines that set the price, as short level-1 lines:
   - "Includes all protection and clean up"
   - "Pricing is based on a 1-prime / 2-finish coat application standard"
   - "Equipment Included" / "Paint Included"
   - "Dumpster not included/Dumpster must be within 100' of Suite"
   - "Roof demolition not included"
   - "All non-sales partitions will receive Level 4 finish" / "Level 5 finish at Sales floor"
8. Exclusions are one short line each ("Roof demolition not included"), never a paragraph.
9. The template adds "*any item not explicitly listed is not included in Scope or Price" at the end of every trade; do not write it.
10. Plain words, no filler ("comprehensive", "ensure", "as needed to complete the work in a professional manner"). If a line reads like a
    machine wrote it, shorten it.

## Sample: DEMOLITION ($22,000)

- Remove and dispose of:
  - Interior wall per demolition plan
  - All plumbing fixtures
  - Compactor door
  - Truck bumpers
    - Prep for new
  - All walls, ceiling and doors
  - All mezzanine completely
  - Ductwork per demolition plan
  - All flooring throughout
  - Existing toilet fixtures
    - Cut and cap lines as required
  - All abandoned conduit, piping and equipment
- Remove and relocate:
  - Roof hatch and ladder
- Roof demolition not included
- Dumpster not included/Dumpster must be within 100' of Suite

## Sample: CONCRETE CUTTING AND POURBACK ($4,900)

- Sawcut concrete for plumbing to lounge sink – 37 lin. ft.
- Trenching for electrical fixtures – 16 lin. ft.
- Prep Trench for pour back – plastic/rebar
- Pour back

## Sample: FRAMING ($197,000)

- Furnish and install interior partition type B (Masonry existing wall)
  - Height: 14'-6" AFF
  - 1 5/8" Metal furring channels, mounted vertically
  - Full height rigid insulation
  - 5/8" GWB on interior side
- Furnish and install interior partition type S
  - Height: 12'-6" AFF
  - 3 5/8" Metal Studs, 20GA
  - 5/8" GWB on both sides
  - Lateral bracing to underside of structure
- All non-sales partitions will receive Level 4 finish
- Level 5 finish at Sales floor

STRUCTURAL FRAMING AND BLOCKING (sub-heading)
- Furnish and install 5/8" Plywood Strapping as required per detail B/C3
- Furnish and install metal framing to wrap all existing structural columns
  - 3/4" furring channels with horizontal stiffeners
  - 5/8" GWB on all exposed faces
    - ACT Column: Up to 12'-6" AFF

## Sample: CARPENTRY ($35,000)

- 286- Install 1/2" x 7.9" x 48" white oak wall panels
  - Rhone: Boston oaks
  - Glue down and/or nail down
- 278- Install 6" vinyl cove base
  - Mannington: 030 Beach sand
- Install 40" x 40" snap frames
- Install wall bumpers
- Install LP Bench and desk
- Install Toilet room accessories
  - Cup dispenser
  - Automatic soap dispenser
  - 36" grab bar
  - Toilet partition / Color: sandy beach #21-50

## Sample: PAINT ($28,100)

- Prime and paint interior surfaces per finish plan, floor plan and elevations
  - 281- Benjamin Moore OC-23 'Classic gray'
    - Sales floor: Eggshell finish
    - Support/Office/Hallway/Columns: Satin-Pearl finish
- Exterior paint: Sign field and band HG standard
- Includes all protection and clean up
- Pricing is based on a 1-prime / 2-finish coat application standard
- Equipment Included
- Paint Included

## Sample: FRAMING with sub-headings (Burlington, $169,900)

TEMP WALLS (sub-heading)
- Furnish and install Temporary Interior Partition Wall Types AP-3 and AP-6 for Temp Office w/Cash Room
  - 3-5/8" and 6" respectively – 20ga
  - 5/8" Gypsum Board on both sides, Moisture Boards where wet
  - Level 3 Finish
  - All walls to extend to 12'-0" AFF

PHASED BOH AND SALES AREA (sub-heading)
- Furnish and Install Partition Wall Type 1D-6 / 6D-6
  - 5/8" Gypsum Board on both sides
  - Level 4 Finish
  - 6" 20 GA Metal Studs to underside of deck
