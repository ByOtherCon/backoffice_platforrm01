# Trade Writing Guide — byOther Construction

Detailed scope language patterns, edge cases, and examples for each trade. Read this file when writing a specific trade section or when dealing with unusual scope conditions.

---

## General Principles

- **Pull language from the plans.** Don't paraphrase — use the exact keynote code and description from the drawings. If the plan says "Remove existing floor drain. The contractor shall cap the abandoned utilities as required." your scope says: `• D-3: Remove existing floor drain; cap all abandoned utilities as required.`
- **One bullet per keynote.** Each demo keynote, floor plan keynote, finish keynote, etc. gets its own bullet.
- **Specs verbatim.** Fixture schedules, finish schedules, and door schedules have model numbers and full descriptions — copy them exactly. Never paraphrase a spec.
- **Owner has first right of refusal on demo material.** Always include this language in Demolition.
- **Coordinate with GC and Landlord.** Every trade section should note coordination requirements where they exist in the plans.

## DEMOLITION

### Standard language block (always include):
```
All demolished material removed from site and disposed of legally.
Owner has first right of refusal on all materials prior to disposal.
NOTE: Dumpster by byOther Construction; dumpster placement must be within 50 feet of building access point. Coordinate with GC and building management.
NOTE: [Any specific exclusions for this project, e.g., slab cutting] is excluded from this scope – see Flagged Items.
```

### Common demo keynote patterns:
| Keynote | Standard language |
|---|---|
| Existing walls/doors/frames remain | `• D-[X]: Existing walls, doors, and frames to remain shall be protected as required throughout demolition and construction.` |
| Remove walls | `• D-[X]: Remove all dashed-line full walls, kneewalls, and soffits from top to bottom of wall. Includes all existing décor, trim, doors, windows, utilities, and/or equipment on or within wall.` |
| Remove floor drain | `• D-[X]: Remove existing floor drain; cap all abandoned utilities as required.` |
| Remove plumbing fixtures | `• D-[X]: Remove existing plumbing fixtures, drains, and supply piping; cap all abandoned utilities at point of origin where no new fixture is installed.` |
| Storefront remains | `• D-[X]: Existing storefront/window system to remain. Protect during demolition and construction.` |
| Remove floor finish | `• D-[X]: Remove existing floor finish and base; prepare substrate for installation of new finishes. Approx. _____ SF (verify in PlanSwift).` |
| Remove ceiling | `• D-[X]: Remove existing ceiling tile, ACT grid, and/or GWB ceiling in this area along with all light fixtures, HVAC ductwork, HVAC diffusers, and all abandoned utilities servicing these devices. Approx. _____ SF (verify in PlanSwift).` |
| Slab cutting | **FLAG — never include in byOther scope** |
| Utilities to remain | `• D-[X]: All existing utilities serving the adjacent tenant and tenants above shall remain and be protected as required during construction.` |

### Plumbing/MEP demo:
When demo plan notes reference MEP demolition, include: `The contractor shall refer to and coordinate with the MEP drawings for all related demolition work.`

## FRAMING

### Partition type header format:
```
PARTITION TYPE #[X] – [Description from wall type sheet] ([new or existing]):
• [Gauge] GA slotted MTL track ([ICC code]). Stud options: A = [size] MTL studs / B = [size] MTL studs / C = [size] MTL studs.
• [GWB type and thickness], [height condition — to ceiling or full height to deck].
• [Insulation if applicable].
• GWB finish: Level [X] minimum.
• Quantity: _____ LF (measure from plan in PlanSwift).
```

### Special framing conditions:
| Condition | Language |
|---|---|
| Deflection track | `20-GA slotted (deflection) track at top — allows vertical movement; do not fasten studs to track at top.` |
| Bridging | `Bridging @ 48\" O.C. vertical unless noted otherwise per framing notes.` |
| Box headers at openings | `Box headers at all door openings per structural requirements.` |
| Ceiling framing | `Metal stud ceiling framing at [height] AFF per RCP; GWB soffit, finish Level [X].` |
| QuietRock | `5/8\" QuietRock ES GWB — do not substitute standard GWB; product-specific acoustic performance required.` |
| Acoustic caulk | `All GWB sealed to floor and roof deck with acoustic caulk per wall type detail.` |

### Blocking scope — always comprehensive:
List every blocking application called out on the plans:
```
• FRT in-wall solid wood blocking at all locations required by plan, including: [list keynote refs — TV mounts, mirrors, fitness equipment, accessories, A/V rack, drinking fountain, hand dryers, grab bars, toilet accessories, etc.].
```

### General framing closing notes:
```
• Metal corner bead at all exterior GWB corners.
• All partition joints spackled, taped, and sanded smooth with no visible joints.
• Fire caulk all penetrations (new and existing) through demising/fire-rated walls.
• GWB installed and taped/bedded to deck on all four perimeter walls.
```

## CARPENTRY

### Door entry format:
```
• Door [number] – Type [letter], [W]'-[W]\" x [H]'-[H]\" x [thickness]\", [Door Type from spec]: [Full description from Door Specification table]. [Finish]. Hardware Set [X]: [list each hardware item with manufacturer and model number from Door Hardware Schedule]. Install frame and door.
```

### Accessory entry format:
```
• [Tag]-[item number]: [Description] – [Manufacturer], Model [model number] ([finish/color]). Qty: [X]. [Any installation note from plans].
```

### Owner-furnished / contractor-installed items:
Use exact FF&E keynote language:
```
• FF&E-[X]: [Item description] – furnished by owner, received and installed by contractor. [Any blocking or backing note].
```

### FRP panels:
```
• [Tag]: [Manufacturer] [Product Name], [model/item number], [color], [size] panels. Installed with all trim accessories per Finish Schedule Key Note [X].
```

## FLOORING

### Tile entry format:
```
• [Tag]: [Manufacturer] [Product Line] [Item Number], [Color Name], [Size]. [Joint size], [grout color] to match, [orientation]. [Installer/vendor note if required]. Installed per TCNA standard details.
• Schluter [profile type] trim at base of wall and all corners.
• [Backer board type] at all wet locations.
• Quantity: _____ SF floor + _____ SF wall (measure from plan in PlanSwift).
```

### Polished concrete:
```
• [Tag]: Contractor shall prep and polish existing concrete floor once previous finishes have been removed. Polish to achieve smooth, commercial-grade finish. Provide crack control joint along length of existing pour strips at cold joints where pour strips connect to main building slab.
• Quantity: _____ SF (measure from plan in PlanSwift).
```

### Athletic turf — owner-furnished:
```
• [Tag]: [Foam pad spec] + [Turf spec], [Color]. NOTE: Turf padding and finish material furnished by franchisee/owner; contractor installs only. [Required vendor note if called out]. Grain direction per finish schedule key note.
• Quantity: _____ SF (measure from plan in PlanSwift).
```

### Vinyl cove base:
```
• [Tag]: [Manufacturer] or equal, Model [number] [Color], [Height]\" vinyl cove base. Installed with all trim accessories.
• Quantity: _____ LF (measure from plan in PlanSwift).
```

## PLUMBING

### Fixture entry format (from P-3.0 schedule):
```
• [Tag] (x[qty]): [Fixture Type] – equal to [Manufacturer] Model [model number], [description from schedule]. Rough-in: [CW size], [HW size if applicable], [waste size]. [Any remarks from schedule — mounting height, trap primer, etc.].
```

### Water heater entry format:
```
• [Tag] (x[qty]): [Type] – [Manufacturer] Model [model number], [description]. [Voltage / phase / Hz / KW]. [GPM @ temp rise]. [Location — wall-mounted below LAV, etc.].
```

### Water piping connection format (from P-1.0 keynotes):
```
• P-1.0-#[X]: [Exact text of keynote — e.g., "Extend and connect new 1\" CW piping to the existing cold water line in space with existing water meter. Contractor to field verify the size, routing and location of existing CW line."]
```

### Sanitary connection format (from P-1.1 keynotes):
Same pattern — use exact keynote text.

### Standard plumbing closing language:
```
• All CW/HW/HWR piping insulated per 2023 Florida Energy Conservation Code.
• Provide branch PRV if pressure exceeds 80 PSI.
• Domestic water piping above grade: Type L hard-drawn copper; fittings copper or copper alloy; lead-free solder joints.
• Sanitary piping: SCH.40 PVC (where permitted by AHJ).
• Permit: Contractor to obtain and pay for all permits and fees; coordinate all required inspections.
NOTE: All slab cutting per Demo Keynote [X] is excluded from this scope – see Flagged Items.
```

## ACT CEILING

### Standard ACT entry format:
```
• Grid/tile: [Manufacturer] Model [number] ([product name, profile, color]), [tile size], [finish]. [Wire suspension spacing]. All lay-in fixtures to have seismic wire supports on two diagonal corners.
• Grids centered in spaces unless noted otherwise.
• [Insulation product (e.g., Rockwool Safe'N Sound)] above all ACT ceilings.
• Supply/return diffusers: [primed and painted to match ceiling / standard white / per spec].
• Quantity: _____ SF (measure ACT areas from RCP in PlanSwift).
```

### Sprinkler note (always include when NFPA 13 building):
```
NOTE: Sprinkler head relocation/modification required per RCP. Sprinkler scope is excluded from this section – see Flagged Items.
```

## PAINTING

### Paint code entry format:
```
[Code] – [Surface description]:
• Paint: [Manufacturer], Color [number] "[Color Name]", [Finish].
• Surfaces: [Describe surfaces — new GWB walls, existing repaired walls, exposed structure, doors/frames, etc.].
• Application: 1 coat latex-based interior primer + 2 finish coats [finish description].
• [Any special prep — Level 4 GWB finish required before paint; dry-fall for exposed structure; etc.]
• Quantity: _____ SF [surface type] (measure from plan in PlanSwift).
```

### Dry-fall / exposed structure:
```
• Application: Dry-fall formulation; spray applied. Protect all finished surfaces, flooring, and equipment below prior to application.
```

### Patching scope:
```
PATCHING SCOPE:
• Patch and repair all existing GWB walls and surfaces that remain. Fill all holes and openings resulting from demolition of abandoned utilities, anchors, or previously removed fixtures. Surfaces to achieve Level [X] finish prior to paint.
```

### Standard closing:
```
NOTE: Painting of all wall surfaces to be completed prior to installation of any wall trim, paneling, or equipment.
```
