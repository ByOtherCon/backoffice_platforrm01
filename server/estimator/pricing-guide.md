# Pricing Guide — byOther Construction (Florida Commercial Market)

Use these rates for trade pricing breakdowns. Always state assumptions and flag quantities that need PlanSwift verification before the number is locked.

**Market tiers:**
- **Standard FL market**: Use mid-range rates below
- **Premium market** (Naples, Miami Beach, Brickell, Palm Beach, Mercato-class retail): Use upper band or add 15–20%
- **Panhandle / rural FL**: Use lower band

**byOther standard margin**: 15% overhead & margin applied to subtotal.

## Notes on Presenting Pricing

1. **Always flag PlanSwift quantities.** Mark any quantity with ⚠ if it was estimated, not measured from plans.
2. **State your assumptions.** List them clearly below the breakdown so the user can validate.
3. **Allowances vs. hard bids.** When uncertain (especially plumbing fixture count, existing conditions), label as "allowance" and recommend a site walk.
4. **Class A / landlord premium.** At Mercato-class properties, add coordination time, dust containment, off-hours scheduling, and potential landlord-required licensed sub requirements to the estimate.
5. **Never price slab work.** Always exclude and flag.
